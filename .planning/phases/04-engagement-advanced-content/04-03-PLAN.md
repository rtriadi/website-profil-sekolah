# Plan 04-03: Content Scheduling & Homepage Spotlight

**Phase**: 4 — Engagement & Advanced Content
**Status**: Draft
**Plan Dependencies**: None (Wave 2 — can start after 04-01/04-02)

## Goal

Staff user can schedule content publish/unpublish windows and configure homepage spotlight modules.

**Requirement mapping**:
- ADVC-01: Staff user can schedule content publishing windows.
- ADVC-02: Staff user can configure richer homepage spotlight modules.

**Human checker**: Create an announcement with a future publish date → confirm it's NOT visible on public page → change date to past → confirm it IS visible. Toggle spotlight on an announcement → see it highlighted on homepage. Remove spotlight → confirm it falls back to normal layout.

## Deliverables

1. **Schema extensions** — add `publishedUntil` and `spotlight` fields to Announcement
2. **Service updates** — filter by publish window, add spotlight query
3. **Admin form updates** — date picker for publish schedule, spotlight toggle
4. **Homepage update** — featured spotlight section
5. **Data file update** — `data/announcements.json` gets new fields

## Files to Create

None — this plan only modifies existing files.

## Implementation Details

### Schema Changes

```typescript
export interface Announcement {
  // ... existing fields
  publishedUntil?: string; // ISO date — undefined means no expiry
  spotlight: boolean;
}
```

### Service Changes

- `getAnnouncements()` — filter out items where `publishedUntil < now` AND items where `publishedAt > now` (scheduled future publish)
- New: `getSpotlightAnnouncements()` — returns spotlight items sorted by recency, up to 3
- Admin list shows "Scheduled" / "Expired" badges based on date windows

### Admin Form Changes

- Add "Tanggal akhir tayang" (optional date input) — if empty, content never expires
- Add "Tampilkan di sorotan" checkbox — labeled "Tampilkan di halaman utama sebagai sorotan"
- Show "Status" indicator in admin list: "Scheduled" (future), "Active" (within window), "Expired" (past window)

### Homepage Changes

- Above "Pengumuman Terbaru" section, add "Sorotan" section when spotlight items exist
- Spotlight section: a large card (first spotlight) and 2 smaller cards
- Empty state: section hidden entirely (falls through to latest announcements)
- Each card: title, summary, date, link to detail

### Data Migration

- `data/announcements.json`: add `"spotlight": false` and `"publishedUntil": null` to existing entries
- Seed data in schema.ts: add `spotlight: false` to all

## Verification

1. `npm run build` passes
2. Create announcement with future publish date → not visible on `/pengumuman`
3. Edit announcement — set publish date to past → visible on `/pengumuman`
4. Set `publishedUntil` to past → announcement disappears from public
5. Toggle spotlight on → appears in homepage spotlight section
6. Remove all spotlights → spotlight section hidden, normal announcements show
