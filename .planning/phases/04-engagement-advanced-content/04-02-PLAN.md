## Implementation Details

### Document Schema

```typescript
export interface SchoolDocument {
  id: string;
  title: string;
  description: string;
  category: "formulir" | "brosur" | "kalender-akademik" | "kurikulum" | "lainnya";
  filename: string;
  url: string;
  fileSize: number;
  uploadedAt: string;
}
```

### Document Service

- Upload to `public/uploads/documents/`
- Validate: PDF, DOCX, XLSX (max 10MB)
- Metadata in `data/documents.json`
- `getDocuments()`, `getDocumentsByCategory()`, `deleteDocument(id)`

### Public Downloads Page

- Grouped by category
- Each card: icon, title, description, download button
- Download button shows file size
- No images — clean list/card layout

### Admin Page

- Client component with server data injection (same pattern as media page)
- Upload form: file input + title + description + category select
- Document list with delete button
