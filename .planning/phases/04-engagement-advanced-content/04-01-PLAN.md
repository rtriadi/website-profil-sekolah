## Implementation Details

### Event Schema

```typescript
export interface SchoolEvent {
  id: string;
  title: string;
  slug: string;
  date: string; // ISO date (YYYY-MM-DD)
  time?: string; // e.g. "08:00 - 12:00"
  location?: string;
  description: string;
  category: "akademik" | "non-akademik" | "libur" | "rapat" | "lainnya";
}
```

Seed with 5-6 events spanning the current and next month.

### Public Events Page Design

- **List view** (simpler than full calendar grid): events grouped by month
- **Category filter**: pills/tabs at top for each category + "Semua"
- Each event card: date badge (day/month), title, time, location, category chip
- Filter via URL search params: `/events?category=akademik`
- Mobile: single column, desktop: 2-column grid
- Empty state: "Belum ada acara" per category
- `generateMetadata` for SEO

### Event Service

Same pattern as announcement-service.ts:
- read from `data/events.json` with seed fallback
- `getEvents()` — sorted by date ascending
- `getEventsByCategory(category)` — filtered
- `createEvent(input)`, `updateEvent(id, input)`, `deleteEvent(id)`

### Admin Event Pages

- List: table with date, title, category, actions
- Create/edit form: title, date (date input), time (text), location (text), description (textarea), category (select)
- Server Actions with validation
