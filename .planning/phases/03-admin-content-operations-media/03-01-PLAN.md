## Implementation Details

### File Storage Pattern (`file-storage.ts`)

```typescript
// src/lib/data/file-storage.ts
import fs from "node:fs";
import path from "node:path";

const DATA_DIR = path.join(process.cwd(), "data");

export function readJsonFile<T>(filename: string, fallback: T): T {
  try {
    const filePath = path.join(DATA_DIR, filename);
    if (!fs.existsSync(filePath)) return fallback;
    const raw = fs.readFileSync(filePath, "utf-8");
    return JSON.parse(raw) as T;
  } catch {
    return fallback;
  }
}

export function writeJsonFile<T>(filename: string, data: T): void {
  if (!fs.existsSync(DATA_DIR)) {
    fs.mkdirSync(DATA_DIR, { recursive: true });
  }
  const filePath = path.join(DATA_DIR, filename);
  fs.writeFileSync(filePath, JSON.stringify(data, null, 2), "utf-8");
}
```

### Announcement Service Extensions

- `getAnnouncements()` — reads from `data/announcements.json`, falls back to seed data, then writes seed to file for future reads
- `getAnnouncementBySlug(slug)` — unchanged but reads from JSON
- `createAnnouncement(input)` — validates, generates id/slug/createdAt, writes
- `updateAnnouncement(id, input)` — finds, merges, writes
- `deleteAnnouncement(id)` — filters out, writes

### Form Component Pattern

- Use native HTML forms with Server Actions (no `"use client"` state for form — Server Actions + revalidation pattern)
- Fields: title (text), content (textarea), category (select: berita/kegiatan/pengumuman), published (checkbox)
- Validation on server side, return `{ fieldErrors?: Record<string, string>, success?: boolean }`
- After create/edit: `redirect("/admin/announcements")`
