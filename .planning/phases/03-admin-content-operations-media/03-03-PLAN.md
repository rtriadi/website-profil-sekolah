## Implementation Details

### Gallery Page Design

- Server Component reading media items from data store
- `generateMetadata` for SEO title/description
- Heading: "Galeri Sekolah" with descriptive text
- Responsive grid: 2 cols on mobile, 3 on md, 4 on lg
- Loading: skeleton grid layout (since images are local, fast loading)
- Empty state: "Belum ada galeri" message

### Gallery Grid Component

- Uses client-side lightbox (interactivity → `"use client"`)
- Receives media items as props (server → client boundary)
- Each image: thumbnail aspect ratio 4:3, object-cover, rounded corners
- Lazy loading via `<Image>` with `loading="lazy"`
- Click thumbnail → open lightbox at that index

### Lightbox Component ("use client")

- Overlay with dark backdrop (bg-black/80)
- Centered image display with `object-contain`
- Previous/next navigation arrows
- Keyboard: Escape (close), Left/Right arrows (navigate)
- Close button (top-right ×)
- Click outside image to close
- Image counter: "3 / 12"
- Smooth fade transition on open/close
- Body scroll lock when open

### Image Display

```tsx
<Image
  src={item.url}
  alt={item.altText}
  width={400}
  height={300}
  className="rounded-lg object-cover"
  loading="lazy"
/>
```

### No External Dependencies

- Lightbox is custom (prevents bundle bloat)
- Uses Next.js `<Image>` for optimization
- No animation library — CSS transitions only

### Gallery Data

Gallery data comes from `getGalleryItems()` in media-service.ts which returns items from `data/media.json`. Any image uploaded via admin media (03-02) automatically appears in the gallery.

Seed data: if `data/media.json` doesn't exist, return an empty array (no fallback seed — gallery starts empty; staff adds images).
