# Pitfalls Research — School Profile Website

## Common Pitfalls

1. **Unstructured content model early on**
   - Warning signs: frequent schema rewrites, duplicated fields
   - Prevention: define core entities up front (profile, page, announcement, media)

2. **No clear editorial workflow**
   - Warning signs: stale public pages, ad-hoc edits
   - Prevention: provide simple publish/update flow in admin with minimal friction

3. **Mobile UX treated as afterthought**
   - Warning signs: navigation overflow, unreadable text blocks
   - Prevention: mobile-first layouts and regular viewport verification

4. **Heavy media without optimization**
   - Warning signs: slow page load and layout shifts
   - Prevention: image optimization, dimensions, CDN caching

5. **Scope creep into school ERP features**
   - Warning signs: backlog filled with grading/attendance modules
   - Prevention: enforce out-of-scope boundaries in PROJECT/REQUIREMENTS docs
